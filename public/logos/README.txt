Provider logos (optional)

Save a logo here as <provider>.svg (or .png / .webp) and the Admin shows it instead of the letter badge.
The name is the provider id: nvidia, zai, google, openrouter, literouter, meganova, groq, amd, deepseek.
Example: public/logos/groq.svg

Only files named like that are served. Delete a file to go back to the letter badge.
